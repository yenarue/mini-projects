# Korea GenAI Research Atlas

국가 R&D 데이터로 보는 대한민국 생성형 AI 연구현황(2023년~2026년 9월 30일).

## 현재 상태

- NTIS 공식 다운로드 4개 검색 패스 수집·통합 완료
- 6,193개 원본 행을 3,241개 과제 ID로 통합하고 관련성·기관 범위를 판정
- 1,698개 연도별 포함 레코드를 1,151개 대표 프로젝트로 연결
- 308개 원본 기관명을 173개 기관, 187개 기관·캠퍼스 위치로 정규화
- 데이터 품질 EDA와 규칙 기반 기술 접근 6개·적용 영역 8개 분류 완료
- 제목·키워드·연구목표·연구내용 기반 키워드·유사 연구·14개 탐색 군집 분석 완료
- 웹 공개용 JSON·CSV와 탐색 분석 워크북 생성 완료
- KAIST ITM 톤의 반응형 HTML 구현과 사용자 화면 피드백 반영

## 구현 화면

- 핵심 수치와 연도별 활성·신규 프로젝트
- 시도 타일 지도·대한민국 실제 지도 전환과 지역별 프로젝트·연구비
- 기관 순위와 기관 집중도
- 기술 접근 6개·적용 영역 8개 규칙 기반 주제군 전환
- 전체·연도별 특징 키워드
- 1,151개 프로젝트의 2차원 연구 지도, 프로젝트별 유사 연구 5개 연결
- 14개 의미 기반 탐색 군집의 규모·연구비·대표 키워드 요약
- 과제명·PI·기관 검색, 지역·주제 필터, NTIS 과제 검색 링크
- 2026년 9월 30일 분석 기준·방법론·데이터 한계 표시

## 탐색 분석 방법

다년도 연차의 중복되지 않은 제목, 한글·영문 키워드, 연구목표요약과 연구내용요약을 대표 프로젝트 단위로 합쳤다. 단어 1~2그램과 한글 띄어쓰기 변형에 강한 문자 3~5그램 TF-IDF를 결합하고, Truncated SVD로 축소한 뒤 k=6~14의 K-means를 비교했다. k=14는 실루엣 0.124로 후보 중 가장 높고 대표 과제가 해석 가능했지만 안정도 ARI는 0.61로 중간 수준이다. 따라서 군집은 공식 학문 분류가 아니라 탐색용 임시 묶음으로만 사용한다.

프로젝트별 유사 연구는 결합 TF-IDF의 코사인 유사도 상위 5개이며, 2차원 지도는 고정 난수 시드의 t-SNE 좌표다. 좌표축 자체에는 의미가 없고 상대적 근접성만 해석한다.

## 데이터 파일

- `data/atlas-data.json`: 메타데이터, 집계, 1,151개 대표 프로젝트와 탐색 분석 파생 결과
- `data/projects.csv`: 같은 프로젝트의 표 형식 공개본
- `data/web_data_dictionary.md`: 공개 필드 정의와 분석 해석 원칙
- `data/skorea-provinces.geo.json`: 통계청 2013년 시도 경계를 단순화한 실제 지도 데이터
- `data/ntis_genai_exploration.xlsx`: 키워드·군집·관계·검증 시트를 포함한 분석 워크북

## 왜 네 번째 검색 패스를 추가했나

처음 세 검색 패스는 과제명·한글 키워드·영문 키워드의 정확구문 검색이라 관련성이 높은 결과를 모으는 데 유리했지만, 같은 개념을 다른 표현으로 쓴 과제를 놓칠 수 있었다. 50건 목적 표본에서 `파운데이션 모델`, 띄어쓴 `대규모 언어 모델`, 검색구 사이에 다른 단어가 들어간 제목, 연구목표·내용에서만 생성형 AI가 핵심인 과제가 반복 확인됐다.

따라서 같은 기간과 기관 범위를 유지한 NTIS 기본 전체검색 `생성형 인공지능`을 네 번째 패스로 추가했다. 새로 발견된 1,450개 ID를 일괄 포함하지 않고 직접 신호와 표본 판정을 이용한 정밀도 우선 규칙으로 다시 걸렀다. 목적은 표본 수 확대가 아니라 정확구문 의존에 따른 표현 편향을 줄이면서 오탐을 통제하는 것이었다.

## 데이터 공개 원칙

- 웹에는 과제명·연도·기관·PI·지역·분류·NTIS 검색 링크와 분석 파생 결과만 포함
- 연구목표·연구내용·기대효과 원문, 사업자등록번호, 연락처, 내부 판정·검토 로그는 포함하지 않음
- 규칙 기반 주제군과 의미 기반 군집 모두 공식 학문 분류가 아님
- 2026년은 9월 30일까지의 진행 중 자료로 표시하고 완결 연도와 직접 증감률로 비교하지 않음
