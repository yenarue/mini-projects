# Korea GenAI Research Atlas

국가 R&D 데이터로 보는 대한민국 생성형 AI 연구현황(2023년~2026년 9월 30일).

## 현재 상태

- NTIS 공식 다운로드 3개 검색 패스 수집·통합 완료
- 4,269개 원본 행을 1,791개 과제 ID로 통합하고 관련성·기관 범위를 판정
- 1,035개 연도별 포함 레코드를 721개 대표 프로젝트로 연결
- 240개 원본 기관명을 136개 기관, 150개 기관·캠퍼스 위치로 정규화
- 데이터 품질 EDA와 기술 접근 6개·적용 영역 8개 주제군 분류 완료
- 62개 주제군 표본 검토 완료
- 웹 공개용 `data/atlas-data.json` 생성 완료
- KAIST ITM 톤의 HTML 구현과 사용자 화면 피드백 반영 완료
- 다음 작업: 누락 위험 보완 점검, 발표·최종 검수

## 구현 화면

- 핵심 수치와 연도별 활성·신규 프로젝트
- 시도 타일 지도·대한민국 실제 지도 전환과 지역별 프로젝트·연구비
- 기관 순위와 기관 집중도
- 기술 접근 6개·적용 영역 8개 주제군 전환
- 과제명·PI·기관 검색, 지역·주제 필터, NTIS 과제 검색 링크
- 2026년 9월 30일 분석 기준·방법론·데이터 한계 표시
- 1440px·768px·375px 반응형 화면과 라이트·다크 모드

## UI 기준

- 상위 `kaist_itm` 페이지의 Pretendard 타이포그래피와 인디고 팔레트 계승
- 카드형 정보 구조, sticky topbar, pill 필터·배지, 반응형 레이아웃 사용
- 기존 `itm-theme` 키를 사용하는 라이트·다크 모드 지원
- 기존 CSS 토큰을 우선 재사용하고 동일 의미의 새 색상 추가 최소화

## 데이터 파일

- `data/atlas-data.json`: 메타데이터, 집계, 721개 대표 프로젝트
- `data/projects.csv`: 같은 프로젝트의 표 형식 공개본
- `data/web_data_dictionary.md`: 공개 필드 정의와 주제군 해석 원칙
- `data/skorea-provinces.geo.json`: 통계청 2013년 시도 경계를 단순화한 실제 지도 보기 데이터

## 데이터 공개 원칙

- 웹에는 과제명·연도·기관·PI·지역·주제분류·NTIS 검색 링크와 집계 결과만 포함
- 연구목표·연구내용·기대효과 원문, 사업자등록번호, 연락처, 내부 판정·검토 로그는 포함하지 않음
- 주제군은 웹 탐색을 위한 규칙 기반 대표 분류이며 공식 학문 분류가 아님
- 2026년은 9월 30일까지의 진행 중 자료로 표시하고 완결 연도와 직접 증감률로 비교하지 않음
