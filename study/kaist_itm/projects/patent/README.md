# 특허 아이디어 작업장

GitHub Pages와 파일 직접 열기를 지원하는 정적 React 웹 UI입니다. 런타임 서버나 API는 없습니다.

## 화면 열기

프로젝트 루트의 `index.html`을 브라우저에서 직접 엽니다. 빌드 결과는 JavaScript·CSS·초기 자료를 포함하므로 인터넷 없이 동작합니다. `dist/index.html`도 같은 파일입니다.

```sh
npm install
npm run dev
# 개발 화면: http://127.0.0.1:5173/app.html
npm run build
# 루트 index.html과 dist/index.html을 새로 생성
npm test
```

개발용 파일은 `app.html`입니다. 이를 파일로 직접 열면 React 소스를 실행할 수 없습니다. 직접 열 때는 반드시 빌드된 `index.html`을 사용합니다.

## 디자인

동일 상위 폴더의 `korea-genai-research-atlas`를 기준으로 배경·카드·브랜드 색상·타이포그래피·모서리·다크 테마를 맞췄습니다. 외부 폰트 요청 없이 설치된 Pretendard 또는 시스템 한국어 서체를 사용합니다.

## 자료와 저장

- 초기 원문·도식은 `.local/catalog.json`에 모아 빌드에 포함합니다. 이 파일은 로컬 전용이며 Git에서 제외합니다. 새 체크아웃에서는 해당 자료를 별도로 준비해야 빌드할 수 있습니다.
- 상담 기록·산출물·버전·첨부·일정은 IndexedDB `patent-workshop-v1`에 저장합니다. 테마 설정만 localStorage를 사용합니다.
- 기록은 브라우저/기기/사이트 주소별로 분리됩니다. file://로 작성한 기록이 GitHub Pages나 localhost로 자동 이동하지 않습니다.
- 산출물 화면의 ZIP 백업·검증·복원으로 기록을 이동합니다. 복원 전 기존 기록을 백업으로 내려받습니다. 브라우저 데이터 삭제 전 백업하세요.
- 새 버전은 불변 스냅샷이며 최신/제출 상태는 별개입니다. Drive 링크는 링크만 보관하고 파일 복사본은 자동 저장하지 않습니다.
- 첨부는 25 MiB 이하 PNG/JPEG/WebP/PDF/DOCX/PPTX/Markdown/TXT를 지원합니다. 브라우저 저장 한도와 메모리에 따라 대용량 백업이 실패할 수 있습니다.

## 배포 파일

정적 호스팅에서 `index.html` 하나로 동작하며 하위 경로를 지원합니다. 공개 배포·커밋·푸시는 이 작업에서 실행하지 않았습니다. 초기 발명 자료는 빌드 HTML에 포함되어 방문자가 볼 수 있습니다. 출원 전 공개 금지 지침 때문에 `.local/`, `index.html`, `dist/`는 Git에서 제외했습니다. 배포가 별도로 승인되면 공개할 초기 자료를 확정하고 배포 파일을 준비해야 합니다.

## 구현 한계

고정 샘플과 명시적 규칙을 이용한 설명용 시연입니다. 실제 AI 추론·학습·로봇 제어·특허성 평가는 하지 않습니다. 미래 유효성 예측과 개인정보 처리 설계도 미정입니다. 다중 기기 동기화나 원격 공동 편집은 지원하지 않습니다.

PRD·PLAN 기준본은 수업 자료 폴더의 `web/`에서 관리합니다. 원본 강의자료와 아이디어 문서는 수정하지 않습니다.
