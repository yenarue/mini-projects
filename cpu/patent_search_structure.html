C. 검색 필드 적용 기준 (Field Application Guide)
검색식 구성요소 내용
검색 필드
선택 기준
TI (Title) 우선 적용
핵심어(Core) 위주 검색. 정밀도(Precision) 극대화 목적. ①②③ 구성요소 중 ①②에 주로 적용.
AB (Abstract) 병행 적용
직접 유사어·확장어 포함. 재현율(Recall) 확보. 구성요소 ③④⑤에 TI/AB 동시 적용 권장.
CPC 코드 병용
G06F 21 (DB 보안), G06N 20 (ML), H04N 1/32 (워터마킹)으로 키워드 노이즈 보완.
운용 원칙 요약 — 구성요소 ①~③은 기술 식별을 위해 AND로 연결하고, 동일 개념 내 유사어는 OR로 확장한다. 구성요소 ⑤(중·소분류 특화 키워드)는 기술별로 교체하여 각 도메인 독립 검색식으로 전환 가능하며, 구성요소 ①②③④⑥⑦은 세 기술 모두에 공통 적용되는 불변 뼈대로 유지한다.
