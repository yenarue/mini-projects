## 6. 라이브 데모

편집기와 미리보기를 나란히 배치한다. 버튼을 기본 진행 경로로 사용하고 직접 입력도 가능하다.

1. **시작:** `E → H·J → C·D·G → F → B`.
2. **병렬 분기 추가:** `H·J → A·I → F` 경로를 추가한다.
3. **방향 변경:** `flowchart LR`을 `flowchart TB`로 바꾼다. 관계는 그대로다.

시연 그래프는 원본의 25개 직접 관계를 모두 표시하지 않는 **학습용 축약 표현**이다. 실제 과제의 심플/상세 그래프와 구분한다.

문법 오류가 나면 이전 정상 그림을 유지하고 초기화로 복구한다. 단계 버튼은 직접 편집 내용을 프리셋으로 덮어쓴다는 점을 화면에 표시한다.

## 7. 마무리: 오늘 기억했으면 하는 세 가지

1. Mermaid는 텍스트로 다이어그램을 만드는 도구다.
2. 생성형 AI와 함께 사용하면 문법을 몰라도 쉽게 시작할 수 있다.
3. 중요한 것은 그림을 예쁘게 그리는 것이 아니라, 표현하려는 관계를 정확히 정의하는 것이다.

이 세 문장을 페이지 마지막에 항상 노출한다. 별도 탭을 열어야 보이는 콘텐츠로 만들지 않는다. 옆에 [Mermaid Live Editor](https://mermaid.live/) 링크와 QR을 배치한다.
